Introdução ao Java Script

Na aula do dia 22 de setembro, o instrutor Victor fez uma introdução ao JavaScript, mostrando como essa linguagem é responsável por controlar a lógica e o comportamento das aplicações na web. Para preparar o ambiente de desenvolvimento no VS Code, montamos a estrutura inicial do projeto criando os arquivos index.html, style.css e script.js.

Logo em seguida, o professor apresentou as ferramentas de inspeção do navegador, dando destaque para a aba de Elementos (para visualizar a estrutura do HTML) e para o Console (onde conseguimos executar comandos). Depois, aprendemos em detalhes como declarar variáveis usando let e const, conhecemos os tipos de dados number, string e boolean, e vimos como utilizar o console.log().

Para colocar tudo isso em prática, realizamos quatro atividades focadas em concatenação e operadores aritméticos. Com o apoio da monitoria para tirar dúvidas e praticar a criação das variáveis, a turma conseguiu transformar a teoria em código com bastante facilidade antes de fazer o envio final dos projetos para o GitHub.
