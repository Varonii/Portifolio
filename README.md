## 📌 Sobre o Projeto

Este repositório contém o código-fonte do meu **Portfólio Pessoal**, desenvolvido para apresentar meus projetos, habilidades técnicas e minha trajetória como estudante e entusiasta da área de tecnologia.

O objetivo da página é servir como uma vitrine interativa e responsiva das minhas experiências com desenvolvimento de software e tecnologias web.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização, layout responsivo e animações.
* **JavaScript (ES6+):** Interatividade e dinamismo das seções.
* **Git & GitHub:** Controle de versão e hospedagem do repositório.
