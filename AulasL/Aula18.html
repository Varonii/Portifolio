Data: 03/08/2026

Turma: 8º e 9º ano

Instrutor:Fatobeni


Box model e Tabelas

A aula de hoje começou com o instrutor Fatobeni explicando como funciona o box model do css, passando por todos os elementos como padding, margin e border, após isso fizemos uma pequena prática para apresentar a ideia de box model, onde eles fizeram tranquilamente. Depois seguimos para mais um conteudo de html, as tabelas, onde foi apresentado todas as tags necessárias para montar uma tabela organizada e bonita, vimos tags como: tabel, thead, tbody, tr, th entre outras. Na ultima parte da aula iniciamos uma atividade onde os alunos teriam que montar uma tabela dos horários de aula deles durante a semana, a maioria dos alunos conseguiu realizar a atividade com certa tranquilidade porém percebi que muitos não conseguiam deixar o código identado e organizado.
